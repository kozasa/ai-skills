# human-handoff

複数エージェントから届く確認依頼や、文章では読みづらい完了報告を、人間が短時間で判断できる形へ整理するルータースキルです。

## 何をするか

- 短い事実・一行の進捗・単純な Yes / No は通常の文章で返します。
- 複数の判断、選択肢、影響、検証結果、リスクがある場合は `quick-html` の FAST モードを使います。
- 並列エージェントからの重複した確認事項をまとめます。
- `review-loop`とPR作成後に、背景・依頼・判断・実装・結果を追える実装ストーリーを作ります。\n- 実画面取得にログインが必要なら、変更操作を架空データで触れる再構成HTMLへ切り替えます。
- 人間の代わりに判断したり、子エージェントへ勝手に回答したりしません。

## 必要なスキル

同じリポジトリにある [quick-html](../quick-html/) も一緒にインストールしてください。

## インストール

ルートの [README](../../README.md) にある Codex / Claude Code 共通の手順を使ってください。

## 自動発火

スキルを配置しただけでも明示的に呼び出せますが、普段の確認依頼で自動的に使わせるには、利用するリポジトリの `AGENTS.md` / `CLAUDE.md`、またはユーザー共通の指示ファイルに発火ルールを追加します。推奨スニペットはルート README にあります。

## 明示的な呼び出し例

```text
$human-handoff
並列エージェントから集まった確認事項を、人間が判断しやすい形にまとめてください。
```

判断事項が十分に複雑なら、ローカル HTML が生成されます。単純な確認なら文章のまま返ります。

```text
$human-handoff
このPRの経緯を実装ストーリーHTMLにまとめてください。
```

対象リポジトリ内だけでなく、PR URLやローカルリポジトリのパスを指定してリポジトリ外からも呼び出せます。
